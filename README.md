# Docimal Admin Dashboard

Admin Dashboard for the Docimal AI Document Automation Platform. Built with Vite, React 19, and Tailwind CSS 4.

## Features

- **Responsive Design**: Mobile-first approach using Tailwind CSS.
- **Modern Tech Stack**: React 19, Vite, and TanStack ecosystem.
- **Authentication**: Pre-configured authentication flows.
- **Dashboard Modules**:
  - **Apps & Integrations**: Manage third-party app connections.
  - **Chatbots & Chats**: Monitor and manage AI chatbot interactions.
  - **Documents**: Document management system.
  - **Audit Logs**: Track system and user activities.
  - **Billing & Usage**: Manage subscriptions and monitor resource usage.
  - **User & Tenant Management**: Multi-tenant support with role-based access control.
  - **Settings & Notifications**: Customizable user preferences and system alerts.
- **Custom Components**: Built-on Radix UI and Shadcn patterns.
- **Advanced Filtering**: Powered by TanStack Table.
- **Charts & Analytics**: Integrated with Recharts.

## Tech Stack

- **UI Framework:** [React 19](https://react.dev/)
- **Styling:** [Tailwind CSS 4](https://tailwindcss.com/)
- **Build Tool:** [Vite](https://vitejs.dev/)
- **Routing:** [TanStack Router](https://tanstack.com/router/latest)
- **State Management:** [Zustand](https://github.com/pmndrs/zustand) & [TanStack Query](https://tanstack.com/query/latest)
- **Data Table:** [TanStack Table](https://tanstack.com/table/latest)
- **Forms:** [React Hook Form](https://react-hook-form.com/) with [Zod](https://zod.dev/)
- **UI Components:** [Radix UI](https://www.radix-ui.com/)
- **Icons:** [Lucide React](https://lucide.dev/icons/)
- **Charts:** [Recharts](https://recharts.org/)

## Run Locally

Clone the project

```bash
  git clone <repository-url>
```

Go to the project directory

```bash
  cd docimal-admin
```

Install dependencies

```bash
  npm install
```

Start the development server

```bash
  npm run dev
```
